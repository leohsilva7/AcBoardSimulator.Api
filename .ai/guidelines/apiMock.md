# Regras e modificações

Esse projeto se trata de uma API Asp Net Core com .NET 10 que envia dados simulados de telemetria de ar-condicionado para tópicos MQTT que são criados com base no ID da placa do aparelho ar-condicionado. Atualmente, essa API cria placas simuladas na memória ao iniciar o projeto pelo método CreateOrResetBoard da classe BoardStateService. Eu preciso que agora as placas sejam buscadas por um banco de dados SQL Server na tabela Boards, coluna ID. Os pacotes do Entity Framework já estão instalados e as credenciais estão armazenas em Secrets seguindo o padrão ConnectionStrings -> DefaultConnection. Você deve implementar a conexão com o banco de dados e substituir o método CreateOrResetBoard por um método que executa um Select na tabela Boards buscando apenas a coluna Id para criar os tópicos MQTT. Você não deve implementar métodos de criar placas ou modificar placas, isso está sob responsabilidade de outra API.
